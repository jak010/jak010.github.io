### 핵심 성과 및 의사결정 이력

#### 1. 기존 가상계좌 결제 시스템의 동작 검증 환경 구성 및 결제 라이프사이클 분석
* **문제**
  - 운영 중이던 가상계좌 결제 서비스가 외부 요인으로 일시 중단된 상황에서, 재개를 위해 전체 결제 라이프사이클이 정상적으로 동작하는지 확인해야 했음.
  - 상용 운영 환경에서 직접 테스트할 경우 실제 자금 이동이 발생하여 회계 데이터 및 계좌 잔액 오염의 우려가 있었음.
* **해결**
  - **검증 환경 구성**: 실제 자금 이동 없이 결제 흐름을 안전하게 테스트하기 위해 외부 핀테크 API(Dozn API) 및 경남은행 테스트 연동망을 활용한 별도의 검증 환경을 구성함.
  - **시스템 동작 추적**: 구성된 테스트망을 통해 가상계좌 발급 ➔ 고객 입금 ➔ 입금 통지 ➔ 대사 정산에 이르는 전체 트랜잭션을 실행하며 기존 코드와 외부 API 간의 통신 과정을 분석함.
  - **예외 상황 검증**: 네트워크 타임아웃, 통지 유실 등 발생 가능한 예외 케이스를 가정하고, 모의 시나리오를 설계하여 기존 시스템의 예외 처리 로직이 올바르게 동작하는지 확인함.
* **성과**
  - 기존 결제 시스템의 수명 주기를 운영 데이터 오염 없이 안전하게 검증할 수 있게 되었으며, 서비스 재개 시 발생할 수 있는 운영 리스크를 낮춤.

#### 2. 기존 결제 시스템의 상태값과 트랜잭션 흐름 분석 및 FSM 기반 구조화
* **문제**
  - 다년간 운영되어 온 핀테크 연동 시스템이었으나, 기존 설계서와 가이드 문서가 현행화되어 있지 않아 시스템의 복잡한 비즈니스 규칙(트랜잭션 대사, 수작업 매칭 등)을 파악하기 어려웠음.
* **해결**
  - **원리 파악 및 구조화**: 기존 데이터베이스의 트랜잭션 로그와 테이블 상태값 변화를 직접 추적하고, 복잡하게 얽혀 있던 결제 상태 전이 과정을 이해하기 위해 FSM(Finite State Machine) 형태로 시각화하여 분석함.
  - **운영 지식 문서화**: 분석한 시스템의 동작 원리와 결제 시나리오를 바탕으로 결제 상태 다이어그램 및 대사 정산 예외 처리 가이드를 작성함.
* **성과**
  - 파편화되어 있던 기존 결제망의 비즈니스 로직과 상태 변화 흐름을 명확하게 파악할 수 있게 되었으며, 문서화된 내용을 통해 이후 시스템 유지보수와 타 부서와의 협업 과정이 수월해짐.
